## 🇬🇧 English

Welcome to the official download repository for the **Kecks Client**. 
This is a custom built, lightweight launcher designed specifically for **The Cookie SMP**, providing a seamless and optimized Minecraft experience.

> **Note:** This repository is used exclusively for distributing the compiled releases. The source code is kept private.

### ✨ Features
* **✅ Automatic Java Setup:** Automatically downloads and configures the correct Adoptium Java version.
* **📊 Live Server Status:** Check the current player count and status of The Cookie SMP directly within the launcher.
* **🚀 Fast & Clean:** Lightning fast startup times and a modern, user friendly interface.

### 📥 Download & Installation
1. Go to the [Releases](../../releases/latest) page of this repository.
2. Download the latest `.exe` setup file under "Assets".
3. Run the installer to install the Kecks Client on your PC.
4. Launch the game and enjoy!

### ⚠️ Important Note Regarding Windows SmartScreen
Because this is an independent, custom built application without a digital certificate, **Windows Defender SmartScreen** might flag the `.exe` as unrecognised. 
* This is a standard false positive.
* To run the client, click on **"More info"** and then **"Run anyway"**.
* ✅ **Safety Proof:** [View the 100% clean VirusTotal scan results here](https://www.virustotal.com/gui/file/49d032c597db6d7f7b5103d655afa60ce65feaabd1f5567a4591b148740d5bcc?nocache=1)
* If you have any concerns, feel free to ask the team on our Discord server!
