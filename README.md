## 🇬🇧 English

Welcome to the official download repository for the **Kecks Client**[cite: 3]. 
This is a custom-built, lightweight launcher designed specifically for **The Cookie SMP**, providing a seamless and optimized Minecraft experience[cite: 3].

> **Note:** This repository is used exclusively for distributing the compiled releases[cite: 3]. The source code is kept private[cite: 3].

### ✨ Features
* **✅ Automatic Java Setup:** Automatically downloads and configures the correct Adoptium Java version[cite: 3].
* **📊 Live Server Status:** Check the current player count and status of The Cookie SMP directly within the launcher[cite: 3].
* **🚀 Fast & Clean:** Lightning-fast startup times and a modern, user-friendly interface[cite: 3].

### 📥 Download & Installation
1. Go to the [Releases](../../releases/latest) page of this repository[cite: 3].
2. Download the latest `.exe` setup file under "Assets"[cite: 3].
3. Run the installer to install the Kecks Client on your PC[cite: 3].
4. Launch the game and enjoy[cite: 3]!

### ⚠️ Important Note Regarding Windows SmartScreen
Because this is an independent, custom-built application without a digital certificate, **Windows Defender SmartScreen** might flag the `.exe` as unrecognised[cite: 3]. 
* This is a standard false positive[cite: 3].
* To run the client, click on **"More info"** and then **"Run anyway"**[cite: 3].
